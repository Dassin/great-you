# 伟大的你 · Great You

[English](./README.md) | **简体中文**

</div>

> 把一句随口的感悟，走完「讨论 → 札记 → 溯源 → 破局 → 契约 → 排版」，沉淀成一份带思想溯源与行动契约的单文件 HTML 专题册。

一个**跨平台 Agent Skill**——纯 `SKILL.md` 工作流，可运行于 WorkBuddy、Claude Code，或任何能加载技能/提示词文件的 AI agent。当你随手记下一句人生感悟、职场困惑或哲思短句，它不会直接给你排版了事——而是先请你坐下，与两千五百年来最会想这些问题的头脑对话，讨论成熟后再落笔成册。

📖 **[查看完整示例《视其所视》](./example/monograph.html)**（克服以貌取人专题册，浏览器直接打开）

---

## ✨ 核心理念

**先讨论，后产出。** 排版是整个流程的最后一步，不是第一步。

**伟大的人与作品优先于网上观点。** 讨论阶段只用模型知识库中的经典论述展开对话，不搜网友评论；WebSearch 只允许用于校核引文措辞与出处，不用于找观点。

**引文零编造。** 所有引文必须逐条对照公开中译本校核，查不到可靠出处就不署引号。

## 🔄 工作流（六步，务必按序）

| 步骤 | 名称 | 做什么 |
|---|---|---|
| 0 | **先讨论** | 基于伟大作家/作品的经典论述，与用户对话式探讨——不产出、不排版，直到内容方向成型、用户认可 |
| 1 | **札记** | 把感悟整理成三则递进（只给一句时拆成「认识 → 困境 → 出路」），收一个点睛句 |
| 2 | **溯源** | 每则札记对接 1–2 位作家/思想家的原文引证，WebSearch 仅用于校核引文出处 |
| 3 | **破局** | 诊断（两股力量的夹击）+ 三个动作（减法/转化/第二空间）+ 尼采永恒回归校准器 |
| 4 | **契约** | 落到本周就能开始的三件具体小事，每件配怎么做、陷阱与检验勾选框 |
| 5 | **排版** | 内容全部定稿、用户认可后，才整合为单文件 HTML 专题册 |

## 📖 专题册章节

```
〇 圆桌        多位伟人跨学科发言（哲学/心理学/社会学/文学同台）
i  札记        三则递进 + 点睛句
ii 溯源        作家引文卡（生卒年 + 作品 + 出处 + 阐释）+ 回响小结
iii 破局       诊断 + 三动作 + 校准器
iv 契约        三张可勾选的本周小事卡 + 签名落款（印章「记」）
v  人物与著作   出场人物导读（一致性校验：零遗漏、零多余）
```

## 💬 触发示例

```
你：  最近总觉得上班像在空转，每天很忙又不知道忙了什么。
      做个知识卡片记录一下这种状态。

AI：  （第0步）这句话接上了马克思的"异化劳动"和叔本华的"无聊"……
      （与你来回讨论几轮，直到你认可方向）

AI：  好，内容定稿。（第1-4步）整理札记三则 → 校核《1844年手稿》引文 →
      给出三个动作 → 落成本周三件小事。

AI：  （第5步）排版完成 → /workspace/monograph.html ✅
```

典型触发语：*"做个知识卡片记录几句话"* / *"把这句感悟整理一下"* / *"思想溯源"* / *"这句话有没有作家阐述过"* / *"这种状态如何破局"*

## 🎨 视觉规范（系列一致性）

- **背景**：深色质感渐变 `linear-gradient(160deg,#0f1419,#1a1625,#14110d)` + 赭金/紫红光晕
- **卡片**：米色纸张 `#f7f2e8 → #efe8d6`，圆角 12px，深阴影 + 纸张纹理
- **强调色**：赭金 `#c9a961`（标题/序号/分隔线）、朱红 `#b8683a`（诊断/陷阱/印章）
- **字体**：Noto Serif SC（中文衬线）+ Cormorant Garamond（罗马数字章节序号）
- **引文块**：左侧 3px 赭金竖线 + 衬线体 + 出处小字
- **落款**：日期 + 朱红圆形印章（「记」字，rotate -8°）
- **对比度铁律**：浅色文字只用于深色背景；米色卡片内一律深色文字

完整结构见 [`assets/monograph-template.html`](./assets/monograph-template.html)——复制结构、替换占位符即可生成新专题册。

## ✅ 质量约定

1. **人物一致性校验**：专题册定稿前强制核对——正文出场人物集合必须与「人物与著作」导读章完全一致，零遗漏、零多余，每人均标注「国籍 · 时代 · 生卒」
2. **引文校核**：所有带引号的引文须对照公开中译本（《史记》《庄子》《列子》《实用人类学》《小王子》《景观社会》《消费社会》《1844年手稿》《快乐的科学》等），出处落款到译本
3. **先讨论后排版**：内容未经用户认可，绝不提前排版
